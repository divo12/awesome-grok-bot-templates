# Leadership Team

A portable Grok and Cursor plugin for a four-role personal company:

```text
L0  CEO
├── L1  CTO
│   └── L2  Repo or organization heads
├── L1  Marketing Head
│   └── L2  Channel or campaign heads
└── L1  Researcher
    └── L2  Topic heads
```

Level 3 specialists are temporary and exist only when a Level 2 head cannot safely hold the required context, independent verification is needed, or separable work must run in parallel.

## Included

- `ceo`: sets direction, routes work, resolves tradeoffs, and reports across the board.
- `cto`: turns product outcomes into reliable software delivery through repo heads.
- `marketing-head`: runs evidence-based channel experiments without unapproved publishing or spend.
- `researcher`: turns uncertainty into decision-ready, source-backed findings.
- `company-leadership`: shared delegation, evidence, escalation, and approval protocol.

Select the CEO for company-wide work. Address `CTO:`, `Marketing:`, or `Research:` through the CEO when you want a Level 1 view. The user communicates with L0 and L1 only; lower levels report upward.

This pack has no MCP server and grants no external authority. Tool access comes from the host; publishing, spending, destructive changes, deployments, permission changes, and commitments in the user's name remain approval-gated.
