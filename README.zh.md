## 入门模板

- [grok-bot-templates](https://github.com/cobusgreyling/grok-bot-templates) - 带评分的操作契约、团队配置文件，以及一个 START.md 安装器。
- [grok-bot-profiles](https://github.com/HAEGONG/grok-bot-profiles) - 可直接粘贴的配置文件，把需求、实现和验证拆开。
- [crew-contract](https://github.com/lsj210001/crew-contract) - Grok Bot 小队的运行协议，包含七字段任务和预算到点即停规则。

## 团队模式

- [grok-factory](https://github.com/jaredtrichard/grok-factory) - 可跟随的套件，分别覆盖软件、研究和通用工作，并由 Firstmate 分流。
- [grok-bot-shopping](https://github.com/steve228uk/grok-bot-shopping) - 购物技能包，为采购型 Bot 提供商家和 Stripe 辅助。
- [thin-grok-bot-deep-work-on-cli](https://github.com/Luca-Blight/thin-grok-bot-deep-work-on-cli) - 让 Grok Bot 网络保持精简，把重活交给 CLI 或云端代理。

## 手册与指南

- [grok-bot-playbook](https://github.com/s-hiraoku/grok-bot-playbook) - 日文实战手册，覆盖角色命名、请求模板和交接文件。
- [learn-grok-bot](https://github.com/yuanyijie/learn-grok-bot) - 一套课程，讲共享电脑底座、技能、沙箱和自动化。
- [awesome-grok-bot](https://github.com/RongleCat/awesome-grok-bot) - 本仓库所仿照的源清单；当你需要更大的 Grok Bot 参考地图时很有用。

## Contributing

添加可直接复制的 Grok Bot 模板、入门包或操作手册。每条只写一行，自己先验证链接，并在所有语言里补同样的简介。然后运行 `python3 scripts/generate_readme.py`。
