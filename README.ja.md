## スターターパック

- [grok-bot-templates](https://github.com/cobusgreyling/grok-bot-templates) - 採点付きの運用契約、チームプロフィール、START.md インストーラをまとめたパックです。
- [grok-bot-profiles](https://github.com/HAEGONG/grok-bot-profiles) - 仕様、実装、検証を分けるコピペ用プロフィール集です。
- [crew-contract](https://github.com/lsj210001/crew-contract) - 7 項目ミッションと予算停止ルールを備えた Grok Bot クルー向け運用プロトコルです。

## チーム構成

- [grok-factory](https://github.com/jaredtrichard/grok-factory) - Firstmate で振り分ける、ソフトウェア・調査・汎用ワーク向けの追従しやすいパックです。
- [grok-bot-shopping](https://github.com/steve228uk/grok-bot-shopping) - 購入担当 Bot 向けの、加盟店操作と Stripe 補助を含むショッピング技能パックです。
- [thin-grok-bot-deep-work-on-cli](https://github.com/Luca-Blight/thin-grok-bot-deep-work-on-cli) - Grok Bot の構成を薄く保ち、深い作業は CLI やクラウドエージェントに渡します。

## プレイブックとガイド

- [grok-bot-playbook](https://github.com/s-hiraoku/grok-bot-playbook) - 役割名、依頼テンプレート、引き継ぎファイルを扱う日本語の現場用ハンドブックです。
- [learn-grok-bot](https://github.com/yuanyijie/learn-grok-bot) - 共有コンピュータのハーネス、スキル、サンドボックス、自動化を学ぶレッスン集です。
- [awesome-grok-bot](https://github.com/RongleCat/awesome-grok-bot) - このスターターの元になった一覧で、Grok Bot の広い参照マップが欲しいときに役立ちます。
