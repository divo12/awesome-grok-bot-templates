## Starter Packs

- [grok-bot-templates](https://github.com/cobusgreyling/grok-bot-templates) - Scored operating contracts, team profiles, and a START.md installer.
- [grok-bot-profiles](https://github.com/HAEGONG/grok-bot-profiles) - Paste-in profiles that split spec, implementation, and verification.
- [crew-contract](https://github.com/lsj210001/crew-contract) - Operating protocol for Grok Bot crews with seven-field missions and stop-on-budget rules.

## Team Patterns

- [grok-factory](https://github.com/jaredtrichard/grok-factory) - A followable pack for software, research, and general work routed through Firstmate.
- [grok-bot-shopping](https://github.com/steve228uk/grok-bot-shopping) - Shopping skills pack with merchant and Stripe helpers for a purchasing Bot.
- [thin-grok-bot-deep-work-on-cli](https://github.com/Luca-Blight/thin-grok-bot-deep-work-on-cli) - Keeps the Grok Bot mesh thin and hands deep work to CLI or cloud agents.

## Playbooks & Guides

- [grok-bot-playbook](https://github.com/s-hiraoku/grok-bot-playbook) - Japanese field handbook for named roles, request templates, and handoff files.
- [learn-grok-bot](https://github.com/yuanyijie/learn-grok-bot) - A lesson set on the shared-computer harness, skills, sandboxing, and automations.
- [awesome-grok-bot](https://github.com/RongleCat/awesome-grok-bot) - The source list this starter is patterned after, useful when you want the broader Grok Bot reference map.

## Contributing

Add copy-pasteable Grok Bot templates, starter packs, or playbooks. Keep each entry to one line, verify the link yourself, and add the same blurb in every language. Then run `python3 scripts/generate_readme.py`.
